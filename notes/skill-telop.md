反映するときは、下の 3 か所をスキル編集画面で置き換えてください。

  明朝に替える案、外の白い縁を外す案、縁を減らして影を下へずらす案も並べたが、**いまの形が選ばれた**。

## 2. 「テロップ」の節を、これで置き換える

```md
## テロップ
- フォント:**RocknRoll One**。npmの `@fontsource/rocknroll-one` に入っているwoffのサブセットを、fontToolsのMergerで1つのTTFにまとめ、`~/.fonts` に入れて使う
- 3層:**内側=話者の色**(ルミ &H00FFD65C、マリョ &H00FC84C0)、その外=白、さらに外=黒。ASSでは同じ行を2レイヤーで出す(下のレイヤーが \bord20 で黒、上のレイヤーが \bord10 で白)
  - **白い文字のとき(話者の色を付けない行・タイトル)は順番が逆で、内=黒・外=白**。
    色の付いた文字は白で背景から離すが、白い文字は黒で締めてから白で縁を取る。
    取り違えると、明るい背景でも暗い背景でも沈む
  - **外側の層は内側より少し細く**(5:4 前後)。均等に巻くと同心円に見えて、どの切り抜きも同じ顔になる
  - 影を落とすなら**真下へずらす**(ぼかしの半分くらい)。縁と同じ中心に置くと、機械が付けた縁に見える
- 大きさ:通常のセリフ112、決めゼリフ最大126。`fs=min(基準, 1020/行の文字幅)`。ASCIIは0.55文字分として数える
- 改行:1行9文字前後(**縦型は1行8〜12文字・2行まで**)。「は・が・を・、・?・!・…」や「から・って・けど・ので・より・まで」、空白で区切る。不自然な改行(例「自動翻訳でき/るぐらい」)になるセリフは、spec側で手動の `\n` を入れる
- **表示時間の下限:文字数 × 0.15 秒 + 0.3 秒**。15文字なら約2.6秒。これを割ると、画面に出ていても読まれない
  - 「日本語は1秒に4文字」は**楽に読める速さ**のほう。これで伸ばすと相槌まで間延びするので、下限には使わない
  - 次の行とぶつかって伸ばせないときは、伸ばさずに言い回しを縮めるか、その行を落とす
- 出現:ポンと弾む(65→110→100%)。決めゼリフ(EMPHリスト)は、小さな回転の揺れとゲーム画面のズームを付ける
  - **1本の中で使う動きは2〜3種類まで。**頭と締めだけ目立たせ、残りは揃える。増やすほど画がうるさくなる
- ジャンルで縁の使い方が変わる。**切り抜きは「バラエティ系」**なので、縁と立体で作る。
  落ち着いた画（スタイリッシュ系）では縁と立体が嫌われ、座布団か落ち影を使う。取り違えないこと
- 聞き取りが怪しいところはユーザーに確認する。ユーザーが「(?)」を付けるよう指定したときはそれに従う(全角の「(?)」)
```

## 3. 「3. 文字起こしとハイライト選び」の末尾に足す

```md
- **声の無いところを whisper に渡さない。**渡すと、黙るのではなく言葉を作る
  (無音や音楽の上に「ご視聴ありがとうございました」が乗るのはこれ)。
  先に声のある区間だけを取り出して繋ぎ、落としたぶんの時刻をあとで戻す
- `condition_on_previous_text` は切る。繋ぐと、いちど言葉を作り始めたときに
  それを手がかりに作り続け、同じ行が何十も並ぶ
- 返ってきた行から、癖の分かっている幻だけ落とす。決まり文句 / 直前と同じ行の繰り返し /
  同じ字が6つ以上続くもの / 1秒に25文字を超えるもの。**迷ったら残す**(消しすぎるほうが手間)
```

## 4. 新しい節「ViViD Edit で組む場合」を、「4. 書き出し(ffmpeg)」の前に足す

```md
## ViViD Edit で組む場合(手で直したいとき)

ffmpeg で一気に焼かず、編集アプリ側で組んで直したいときはこちら。
`https://github.com/Oz-k17/vivid-edit` を落として:

    npm run autoedit -- --video <素材> --src <素材フォルダからの相対パス> \
      --transcript <書き起こし> --from <秒> --to <秒> --layout three \
      --title '<見出し>' --out 切り抜き.vivid.json

できたファイルをアプリの「設定 → プロジェクトの受け渡し」から開き、
左の**「台本」**タブで気に入らない行だけ書き換える(読むには短すぎる行には印が出る)。

テロップの体裁の対応:

| ここで言う形 | アプリのプリセット |
| --- | --- |
| 白文字 + 黒の縁 + 外に白の縁 | `テレビ風`(本文) / `見出し（幅いっぱい）`(タイトル) |
| 話者の色 + 白 + 黒の3層 | `3層フチ` |
| 縁を使わず帯を敷く | `ざぶとん` |
| 鮮やかな色 + 縁 + 厚み | `立体` |
| コメントカード | `コメントカード` |

セグメント頭のズームや決めの一瞬は、エフェクトの「頭だけ」「一瞬」で作る。
```
