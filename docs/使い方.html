ViViD Edit

縦型のショート動画（TikTok / Instagram Reels / YouTube Shorts）を作るための動画編集アプリです。 ブラウザの中だけで動き、動画がどこかへ送られることはありません。

この README は操作説明書です。作りの理屈や開発の手順は TECHNICAL.md にまとめています。

ダウンロード

使う端末のボタンを押すだけです。いつ押しても、その時点の最新版が落ちてきます。

端末 ダウンロード 落としたあと
iPad ⬇ iPad 用 「ファイル」で ZIP をタップ → 出てきた ViViD-Edit フォルダの ViVidEdit.swiftpm をタップ → Swift Playgrounds で ▶
パソコン ⬇ パソコン用 ZIP を展開 → ViViD-Edit フォルダの index.html をブラウザで開く
iPhone （ZIP では動きません） 下の「iPhone で使う」
いまの版: **2026-11-14 09:17（日本時間）** に組み立てたもの

この説明書は、ZIP を展開した ViViD-Edit フォルダの「使い方.html」でも読めます（パソコン版・iPad 版とも。ネットにつながっていなくても開けます）。

  • 新しい版が出ると、アプリが知らせます。 開いたときにネットにつながっていれば、画面の下に 「新しいバージョンがあります」とダウンロードのボタンが出ます（6 時間に 1 回まで。つながらなければ何もしません）
  • 最新かどうかは、アプリの「設定 → このアプリについて」の「組み立て」の日時が、上の「いまの版」と同じかで確かめられます
  • ソースも含めた全部入りは ViViD-Edit-main.zip（開発する人向け）

古いものが開いてしまうとき（ダウンロードし直したのに直っていない）:

  • 前に展開したフォルダが残っていませんか。 同じ場所でもう一度展開すると、新しいほうは ViViD-Edit 2 や ViVidEdit 2.swiftpm のような別の名前になり、 古いほうを開き続けてしまいます。古いフォルダと ZIP を消してから、ダウンロード・展開し直してください
  • iPad の Swift Playgrounds は、前に開いたアプリの一覧を覚えています。 一覧にある古い「ViViD Edit」を開くと古いままです。 一覧から古いものを削除し、新しく展開した ViVidEdit.swiftpm をタップして開き直してください
  • ブラウザが古いダウンロードを使い回していないか。 保存先に ViViD-Edit-iPad (1).zip のような名前で増えていたら、新しいほうを展開してください

開き方

パソコン

ZIP を展開して index.html をブラウザで開くだけです。インストールは要りません。

iPad

ZIP を展開してできた ViViD-Edit フォルダの中の ViVidEdit.swiftpm を Swift Playgrounds で開いて ▶ を押します。 ブラウザ版と違い、書き出した動画をカメラロールへ直接保存できます。 くわしくは ios/ViVidEdit.swiftpm/README.md を見てください。

iPhone で使う

iPhone には Swift Playgrounds が無く、Safari は「ファイル」の中の HTML を動かせないため、ZIP では使えません。次のどちらかで使います。

  • URL で開く（いちばん手軽） — GitHub のリポジトリの Settings → Pages で、Source を Deploy from a branch、 ブランチを main、フォルダを /docs にして Save します。数分後に https://oz-k17.github.io/ViViD-Edit/ で開けるようになります（公開したくなければ設定しなくて構いません）
  • Mac の Xcode でアプリとして入れる（カメラロールへ保存できるのはこちらだけ）

はじめの 4 ステップ

初めて開くと、画面に「はじめかた」が出ます。

  1. 動画を選ぶ — 「動画を選ぶ」ボタンで編集したい動画を選びます（何本でも）。そのままタイムラインに並びます
  2. いらない所を切る — 切りたい所で止めて「分割」。いらない部分を選んで「削除」
  3. 文字を入れる — 「＋ テロップ」を押して、文字を打ちます
  4. 保存する — 右上の「書き出し」から動画を出力します

  • 選んだ表示はこのブラウザに覚えます

パソコン表示 / スマホ表示

上のバーの小さなボタン（🖥 / 📱）で切り替えます。勝手に切り替わることはありません （初めてのときだけ画面の幅で決め、以後は選んだほうを覚えます。幅 900px 未満ならスマホ表示から始まります）。

スマホ表示では 1 列になり、

  • プレビューがいつも画面の上
  • 分割・削除・テロップ追加は、キーボードなしで押せるボタン列に
  • 素材 / 編集 / タイムラインは下のシートで切り替え
  • シート上部のつまみを上下にドラッグして高さを変更、タップでたたむ（プレビューを大きく見られます）
  • 上のバーは 2 段になり、「書き出し」が必ず見えます

パネルの配置を変える（パソコン表示）

素材・インスペクタ・タイムラインは、見出しを掴んで左 / 右 / 下のどこへでも移せます。 境目をドラッグすると幅や高さを変えられます。配置は保存されます。

  • 重ねてタブにする — 他のパネルの見出しのあたりへ落とすと、同じ場所に重なってタブになります
  • しまう — 見出し右端の × で消せます。戻すのは上のバーの「⊞ パネル」から
  • 元に戻したいときは「設定 > 編集画面のレイアウト」から初期状態に戻せます
  • タイムラインの初期の高さは、画面の高さの半分弱です（トラックが 5 段ほど見える高さ）。前の版の高さ（300px）のまま変えていなかった人は、自動で新しい高さになります

素材を入れる・整理する

入れる

  • 素材パネルの 「追加」 から、動画・画像・音声を選びます。画面へファイルをドラッグ＆ドロップしても入ります
  • 入れた素材はブラウザの中に保存されるので、ページを移動しても、読み込み直しても残ります
  • 素材パネルは一覧で並び、多いときは「さらに表示」で続きを出します

ビン（フォルダ）で分ける

素材は、フォルダ（ビン）を入れ子にして整理できます。エディタの素材パネルと素材管理ページで同じ操作です。

  • 新しいビン — 選んでいるビンの中に作ります（何も選んでいなければいちばん上）。名前は Enter で確定、Esc で取り消し
  • 移す — 素材もビンも、ドラッグして別のビンへ。ビンを動かすと、中身も一緒に付いていきます
  • 名前を変更（F2）— 同じ場所に同じ名前は作れません
  • 削除 — **素材は消えません。**中身は一つ上のビンへ移ります
  • キーボード — ↑↓ で移動、→ で開く、← で閉じる
  • 検索 — 名前とビンの名前を探します。空白で区切ると、全部を含むものだけ出ます
  • 「未分類」「絵文字」はアプリが使うので、名前変更・移動・削除はできません（中にビンを作るのは自由）

まとめて選ぶ・並び替える

  • 選ぶ: クリックで 1 つ、Ctrl/⌘+クリックで足し引き、Shift+クリックで範囲、Ctrl/⌘+A で全部、Esc で解除
  • まとめて操作: 選ぶと出る帯から、ビンへ移す・削除（確認あり）・タイムラインへ置く。Delete で削除、Enter でタイムラインへ
  • ドラッグ: 選んだ素材をつかむと、選んだ全部を運びます（タイムラインへは隙間なく並べて置きます）
  • 並び替え: 追加順・名前・長さ・サイズ・種類。同じ項目をもう一度押すと逆順。選んだ並びは覚えています
  • 素材管理ページでは、各行のチェックボックスで選びます。「表示中をすべて選ぶ」もあります

色タグとメモ

「採用」「あとで」「ボツ」のような、自分だけの印を付けられます。

  • 色タグ: 赤・橙・黄・緑・青・桃・灰の 7 色。素材を選ぶと下のバーに色のボタンが出ます。同じ色をもう一度押すと外れます
  • メモ: 素材を 1 つだけ選ぶと、メモ欄が出ます（500 文字まで）。入力欄を離れると保存されます
  • 絞り込み: 一覧の上の色ボタンを押すと、その色の素材だけを出します。「色なし」で未整理のものだけを見られます
  • 検索: メモの中身や色の名前（「赤」など）でも探せます
  • 色とメモはこの端末の中だけの情報で、他の人には共有されません

タイムラインで編集する

映像 2 段（V1 / V2）、テロップ 1 段（T1）、音声 2 段（A1 / A2）に並べて編集します。

基本の操作

  • 並べる — 素材をタイムラインへドラッグ＆ドロップ（ダブルクリックでも再生位置へ置けます）
  • 長さを変える — クリップの左右の端をドラッグ
  • 動かす — クリップをドラッグして、時間の方向・段の方向へ（重なった部分は上書きされます）
  • 分割 — 再生位置で C
  • 削除 — Delete。Shift+Delete で、後ろを前へ詰めて削除
  • 吸着（スナップ） — 他のクリップの端・再生位置・0 秒にくっつきます
  • 拡大 / 縮小 — タイムラインの上で Ctrl/⌘+ホイール（トラックパッドや iPad ではピンチ）。カーソルのある所を中心に広がります。右上の −／＋ やキーで変えたときは、再生位置を中心にします
  • 再生位置を動かす — 目盛りをクリック / なぞる。再生位置の上のつまみを掴んで左右に動かしても同じです
    • タイムラインの右上に 横（時間の幅）と 縦（トラックの高さ）の −／＋ があります。トラックが多くて見切れるときは、縦の − で低くすると一度にたくさん見えます（8 段。最初は低いほうから 3 段目で、そこから 2 回縮めるといちばん低く、5 回広げるといちばん高くなります）。縦の倍率は次に開いたときも残ります
  • 複数選択 — Shift+クリック（もう一度で外す）、または空いた所をドラッグして囲む
    • 指で触る端末（iPad など）とスマホ表示では、タイムラインの上に 「複数選択」 のボタンが出ます。オンの間は、タップしたクリップを選び足します（もう一度タップで外す）
  • 右クリックのメニュー — クリップを右クリック（指では長押し）すると、分割・複製・コピー・切り取り・貼り付け・削除が出ます。空いた所なら、そこへ再生位置を移して貼り付けられます
  • 複製（Ctrl/⌘+D、または「複製」ボタン）— 選んだクリップを、すぐ後ろへもう 1 本置きます。後ろのクリップは送るので、何も上書きしません
  • コピー / 切り取り / 貼り付け（Ctrl/⌘+C / X / V）— 再生位置へ貼ります。続けて貼ると後ろへ順に並びます
    • つないだ映像と音は、2 本そろって運びます。まとめたクリップの中と外のあいだでも貼れます
    • 「かんたん」と「挿入配置」のときは後ろを送って差し込み、それ以外は上書きします
  • ボタンのキー — ボタンにマウスを載せると、そのボタンのショートカットキーが出ます
  • 指で触る端末（iPad・スマホ）では、ボタンを長押しすると、同じ説明と動く見本が出ます（タップは、そのままボタンを押します）
  • 元に戻す / やり直す — 60 回以上
  • 段ごとの表示 / ミュートの切り替え

まとめる（ネスト）

何本かのクリップを、タイムライン上で 1 本のクリップにまとめられます（Premiere の「ネスト」と同じ）。

  • まとめる — クリップを 2 本以上選んで（Shift+クリックなど）、インスペクタの「1 つにまとめる」。右クリック（指なら長押し）のメニューの「1 つにまとめる」でもできます
  • 中を直す — まとめたクリップをダブルクリック（またはインスペクタの「中身を編集する」）。中の 1 本 1 本を、ふつうに直せます。 タイムラインの上の「外へ戻る」で外へ戻ります。中にいるあいだ、プレビューは中身だけを映します
  • 外では 1 本として扱えます — 動かす・頭や終わりを詰める・分割・削除。プレビューと書き出しでは、中身がそのまま合成されます
  • 場面の変わり目で分割（シーン分割） — まとめたクリップ（3 分割など）を選ぶと、インスペクタの 自動 タブに「場面の変わり目で分割（シーン分割）」が出ます。中でいちばん大きく映っている映像（3 分割なら真ん中の本編）でカットの切り替わりを探し、まとめたクリップごと割ります。割ったそれぞれの中身は、その範囲だけになります（「戻す」で戻せます）
  • 外で切ると、中身にも移ります — 外で分割すると、左の中身は切った所まで、右の中身は切った所から（頭が 0 秒）になります。頭や終わりを詰めたときも、中身はその分だけになります。中に入ると、見えている所だけが並びます
    • 詰めて隠した所は中身から消えるので、あとから端を引っぱって戻すことはできません（「戻す」で戻せます）
  • まとめを解く（グループ解除） — まとめたクリップを選び、インスペクタの まとめを解く（「中身を編集する」の下）、または右クリック（長押し）のメニューの まとめを解く で、中身を元のトラックへ戻します。戻した中身が選ばれた状態になります
    • 何本か選んでから右クリックすると、「まとめを解く（○ 本）」でまとめて解けます
  • 見どころを探す — まとめたクリップ（3 分割など）の中でも、見どころを探せます（素材の一覧の「おまかせ下書き」と同じ探し方）。インスペクタの 自動 タブの「見どころを探す」で長さ（30 / 45 / 60 秒）を選んで押すと、中の音から盛り上がった所が並びます
    • 見る: その場面へ飛んで再生します
    • ここだけ残す: このまとめたクリップを、その範囲だけにします（中身も）
    • 後ろに足す: その範囲の写しを、タイムラインのいちばん後ろに並べます。元はそのままなので、何本でも作れます
    • 間を詰めたあとのまとめでも、詰めたあとの時間で探します。一度調べた録画は、選び直すとすぐに候補が出ます
  • 映像と音をつないであれば、音も一緒に中へ入ります
  • 縦 3 段に組むときは、最初から 1 本にまとまります（「組んだあと 1 つにまとめる」を外すと、これまでどおり 3 本で並びます）

繋ぐ（分割を戻す）

分割したクリップを、1 本に戻せます。戻したい 2 本（以上）を選んで、インスペクタの「繋ぐ（分割を戻す）」を押します。

  • 同じ素材で、隣り合っていて、切れ目で素材の時間も続いているものだけを繋ぎます（間を消して詰めたものは、話が飛ぶので繋ぎません）
  • 映像と音をつないであれば、音も一緒に繋がります
  • まとめたクリップどうし（分割した 2 本など）も、隣り合っていれば繋げます。中身も 1 つに戻ります

テンポ（間を詰める）

間を詰める・場面で分ける・顔に合わせる・表紙の候補・見どころを探すといった、押すと自動で直す機能は、説明が長くて設定の欄を縦に長くしていたので、インスペクタの 自動 タブにまとめてあります（プロパティのタブは、大きさや位置などの手で直す設定だけ）。

しゃべりの「間」（音の無い所）を、つまみ 1 本で詰めます。

  1. 動画（または音）のクリップを選び、インスペクタの 自動 タブの「間を詰める（テンポ）」で 間を調べる を押す
  2. つまみを ゆったり 〜 きびきび で動かすと、何か所・何秒詰まるかがすぐ出ます
    • ゆったり: 0.9 秒より長い間だけ詰める。きびきび: 0.25 秒の間まで詰める（息継ぎまでは詰めません）
    • 声の頭と終わりには少し余白を残すので、言葉が切れて聞こえません
  3. 間を詰める を押す。気に入らなければ「戻す」で元どおり
  • つないだ音（映像）も一緒に詰まり、同じトラックの後ろのクリップも寄ります
  • BGM・字幕など、ほかのトラックは動かしません。3 分割や字幕より先に使うのがおすすめです
  • 3 分割してまとめたクリップにも、丸ごと使えます。 まとめたクリップを選ぶと、同じく 自動 タブに出ます。中の 3 本の帯・音・見出しを同じ所でまとめて詰め、まとめたクリップが短くなります（見出しは切れずに、全体にかかったまま）
  • 音量で見ているので、BGM やゲームの音が鳴り続けている所は「間」になりません
  • 20 分より長いクリップは調べません（分割してから使ってください）

映像と音

動画を置くと、映像は映像の段（V1 など）、音は音声の段（A1 など）に分かれて並びます。2 本はつながっていて（🔗 の印）、 動かす・長さを変える・分割・削除が、そろって動きます。

  • 音は、空いている音声の段に置きます（BGM がある段には重ねません。空きが無ければ段を足します）
  • 映像を選んで音量やミュートを変えると、音の側が変わります
  • 別々に動かしたいときは、インスペクタの「つなぎを外す」。外したあとも、音は音声の段の側で鳴ります
  • 前に置いた動画は、インスペクタの「音を音声レーンに分ける」で同じ形にできます
  • 音の入っていない動画は、映像だけを置きます
  • 場面の切り替え（ディゾルブなど）を付けても、分けた音は切り替わりの所で重ならず、そのまま切り替わります

場面の切り替え（トランジション）

クリップの継ぎ目のアイコンを押すと、次の 5 つを長さ付きで選べます。カーソルを合わせると、切り替わり方が動いて見えます。

  • 重ねて切り替え（ディゾルブ） / 暗転して切り替え（フェード） / 横へ押し出す（スライド） / 端から拭き取る（ワイプ） / 白く光って切り替え（フラッシュ）

編集ツール（くわしく表示）

タイムライン上部の「編集ツール」の行で、ドラッグしたときの動き方を切り替えます（Premiere と同じ考え方です）。

「くわしく」のボタンの名前は専門用語（Premiere と同じ呼び名）、「かんたん」ではやさしい名前に専門用語を添えた形です。ボタンにカーソルを合わせると、何が起きるかを言ったやさしい名前（「詰めて伸縮」など）と、 クリップがどう動くかの動く図、ひとことの説明、ショートカットキーが出ます。

モード（キー） 端をドラッグ クリップをドラッグ
通常（V） 長さを変える（空いた所は残る） 移動
リップル（詰めて伸縮・B） 長さを変える＋後ろのクリップも一緒に動く 移動
ロール（境目を動かす・N） 隣のクリップとの境目だけが動く（全体の長さは変わらない） 移動
スリップ（中身をずらす・Y） 長さを変える 位置と長さはそのまま、使う場面だけをずらす
スライド（位置をずらす・U） 長さを変える 位置を動かし、前後のクリップが伸び縮みして埋める
  • 押している間だけ切り替え: 端は Alt でリップル・Ctrl/⌘ でロール、クリップ本体は Alt でスリップ・Ctrl/⌘ でスライド
  • 挿入配置（割り込ませて置く・J）: オンの間、素材を置くと上書きせず、後ろへ送って差し込みます
  • In / Out（範囲の始め / 終わり・I / O）を決めて、リフト（範囲を消す・;: 隙間を残す）か抽出（範囲を消して詰める・'）。範囲を取り消すのは Ctrl/⌘+Shift+X
  • 隙間を詰める（Alt+Delete）、全トラック分割（全部の段を分割・Ctrl/⌘+K）
  • スナップ（ぴったり合わせる）: 動かしたクリップが、他のクリップの端や再生位置に吸い付きます。追従（再生に合わせて送る）: 再生中、タイムラインが自動で先へ送られます
  • 前後の編集点へ移動（↑ ↓）、少しずつ動かす（Alt+← Alt+→ で 1 コマ、Shift で 5 コマ）
  • スマホ表示では、ツールの行が横にスクロールします

長い動画を飛ばし見する

3 分以上の動画は、開くと裏で「下見の絵」を作ります（作成中は素材カードに「下見 ○%」と出ます）。 できあがると、再生位置をドラッグしている間はこの絵がすぐ出るので、長い動画でも固まりにくくなります。

おまかせ下書き（長い録画から見どころを探す）

配信の録画のような長い動画から、見どころの候補を探して、そのまま下書きに組みます。文字起こしは要らないので、iPad でも使えます。

  1. 素材の一覧で、1 分半より長い動画（または音）を 1 つだけ 選ぶ。下に「おまかせ下書き」が出ます
  2. 候補の長さ（30 / 45 / 60 秒）を選んで 見どころを探す。録画の音を頭から調べます（3 時間の録画で数分。途中で中止もできます）
  3. 候補が、点数の高い順に最大 5 つ並びます。それぞれに 理由（どの信号が重なったか）が 1 行で出ます。見る でその場面を再生して確かめられます
  4. 下書きにする を押すと、その場面を切り出して組みます
    • 間を詰める（ふつうの強さ）と 3 分割に組む を入れておけば、そこまで済みます。3 分割は、自分の型があればいちばん新しい型の位置と見出しの体裁で組みます
    • 下書きは「下書き」という 1 本のまとめたクリップになります（ダブルクリックで中を直せます）
    • タイムラインに何かあるときは、置き換えてよいか聞きます。「戻す」で前の状態に戻せます
  5. 見出しは「見出しを入れる」のまま入るので、書き換えてください（書き出しの確かめリストでも知らせます）

候補の選び方（複数の信号の重なり）

次の信号のうち、2 つ以上が約 30 秒以内に重なった所だけを候補にします。1 つだけの所は出しません（弱い所で数を埋めない）。

信号 何を見るか 要るもの
音が大きくなった ふだんより声や音が大きい なし（録画の音）
声が高まった 音の高い成分が増えた（叫び・笑いで増える。音だけの目安） なし（録画の音）
チャットが盛り上がった 10 秒に 4 件以上、かつふだんの 2 倍 チャットのファイル
盛り上がる言葉 「やばい」「勝った」「草」などが続いた 文字起こしのファイル（または、下の「軽いモデルで全編を起こす」）
  • チャットのファイル は、TwitchDownloader の JSON・chat-downloader の JSON・[1:23:45] 名前: 文 の形のテキストを読めます。取れなかった日は足さなくて構いません（残りの信号で選びます）
  • 文字起こしのファイル は、Whisper の JSON・SRT・VTT を読めます
  • 重なる所が 1 つも無いときは、そう知らせます。「音の大きさだけで探す（信号 1 つ）」を押すと、これまでどおり音の大きさだけの候補を出します
  • 軽いモデルで全編を起こす（NAS など、文字起こしが使える所だけ）: いちばん軽いモデルで全編を起こして「盛り上がる言葉」の信号にします。20 分ぶんずつ進み、終わった所から候補に効きます。 起こした文字はファイルに取っておけます（次は「文字起こしのファイルを足す」で読むだけ）。字幕にするときは、選んだ場面だけを「字幕」の欄で良いモデルで起こし直します（2 段構え）

候補の評価（良い / 違う）

  • 候補ごとに 良い / 違う を付けられます（もう一度押すと取り消し）。評価はこの端末の中に覚えます

  • 6 件たまると、良いと言った候補に多かった信号を重く見て並べます（例: チャットが重なった候補を良いと言うことが多ければ、チャットの重なった候補が上に来る）

  • 「違う」と言った候補は、後ろへ回します

  • 頭と終わりは、近くのいちばん静かな所に合わせます。山（いちばん盛り上がった瞬間）は、候補の後ろ寄り（前振り → 山 → 余韻）に来ます

  • 一度調べた録画は、選び直すとすぐに候補が出ます（アプリを開き直すまで）

見た目を整える

  • 画角 — 9:16 / 1:1 / 4:5 / 16:9
  • フレームレート — 24 / 25 / 30 / 50 / 60 fps。最初に置いた動画に自動で合わせます。食い違うと「◯◯ fps に合わせる」が出ます
  • 背景ぼかし — 横長の素材を縦型に置いたときの上下の余白を、同じ映像のぼかしで埋めます（強さ・拡大率を調整できます）
  • クロップ（切り抜き） — 入れると、プレビューを指やマウスでなぞって切り抜く範囲を決められます
    • 8 つのつまみで大きさを、内側のドラッグで位置を変えます
    • 縦横比を固定できます（フリー / 画角 / 1:1 / 4:5 / 9:16 / 16:9）
    • 「画角いっぱいに」で、縦横比を保ったまま寄れます
    • Enter / Esc で完了。数値での微調整もできます
  • 縦 3 段に組む（3分割）（上＝見出し・中＝本編・下＝顔のアップ） — クリップを選んで「見出しつきで組む」（または「見出しなしで組む」）を押すと、3 本に置き換わり、1 本にまとまります（ダブルクリックで中の 3 本を直せます。上の「まとめる」）
    • 切り出す場所は中心から取ってあるので、まとめたクリップの中に入り、下の帯（顔）や中の帯を選んで、クロップの「プレビューで範囲を選ぶ」を押します
    • 元の絵の全体が画面に収まって出るので、使いたい所（顔など）を囲みます。帯の置き場所は動かず、枠の形も帯に合わせて決まります
    • 前に組んだ 3 分割では、クロップの「置き場所を固定して、切り抜く範囲だけ選ぶ」を入れると、同じように選べます
    • 顔の位置（レイアウト）: 録画によって、顔（カメラ）が映っている所は違います。「縦 3 段に組む」の下の レイアウト で、中心から / 顔は右下 / 左下 / 右上 / 左上 / 保存した自分の型 から選んでから組むと、顔の帯がその位置を切り抜きます（上と中の帯は中心から）。最後に選んだものが、次も選ばれています
    • 組んだあとで変える: まとめたクリップ（または 3 分割の帯）を選び、レイアウトを変える で選び直すと、帯の切り抜き位置だけが変わります（間を詰めて帯が分かれていても全部。時間や音はそのまま。「戻す」で戻せます）。自分の型を選ぶと、見出しの体裁もその型に変わります
    • 自分の型: 位置を合わせ終えたら、まとめたクリップ（または中の帯）を選んで「この 3 分割を自分の型にする」。 次からは「縦 3 段に組む」を押すだけで、同じ切り抜き位置・同じ見出しの体裁で組めます（作った型が「レイアウト」で選ばれています。人ごとに型を作っておけば、レイアウトで選び分けられます）
    • 型は、解像度の違う録画に当てても絵がつぶれません。隅に合わせた顔は、隅のままです
    • 型の名前の変更・削除は、テンプレートのページで
  • 調整 — 不透明度・大きさ・位置・回転・速度（0.25〜3 倍）・前後のフェード
  • エフェクト — 明るさ / コントラスト / 彩度 / モノクロ / セピア / 色相 / ぼかし / 反転を、強さを決めて重ねがけ。色味のプリセットも 6 種
    • iPadOS 17 以前の iPad では、色のエフェクト（明るさ・モノクロなど）が映りません（Safari が対応したのが 18 から）。その端末では、エフェクトのタブの上に知らせが出て、効かないエフェクトの名前も出ます。ぼかしと背景ぼかしは、簡易な描き方で代わりに映します（書き出しも同じ）。iPadOS 18 以降にすると、すべて使えます
  • 動きを付ける — 色ではなく、絵の動きを付けるエフェクトです。エフェクトのタブの「動きを付ける」から足します
    • じわっと寄る（クリップの頭から終わりまで、ゆっくり寄る） / 一瞬寄る（頭でぐっと寄ってすぐ戻る） / 寄ったまま（ズーム）
    • 一瞬揺らす / 揺らし続ける / 周りを暗く
    • 足したあと、強さと「効かせる時間」を変えられます。3 分割の帯に掛けても、隣の帯へはみ出しません
    • エフェクトや色味のボタンにカーソルを合わせると、選んでいるクリップの絵にかけた見本が出ます（左が元、右がかけた後）
  • エフェクトを効かせる時間 — エフェクトごとに ずっと / 頭だけ / 一瞬 / 入ってくる / 抜けていく を選べます
    • 「頭だけ」で 0.25 秒のズーム、「一瞬」で決めゼリフの所の瞬き、などが作れます
    • いつから / どれだけ / 立ち上がり / 抜け は秒で細かく決められます

テロップと字幕

テロップ

  • 「＋ テロップ」（T）で追加し、文字を打ちます
  • スタイルと「出てくるときの動き」は、ボタンにカーソルを合わせると、いまの文字で見本が出ます（選ぶ前に確かめられます）
  • スタイル（19 種） — 使いどころで 4 つに分けて並べてあります
    • 字幕向け: 白文字＋黒フチ / テレビ風（黒フチ＋白フチ） / 黒い帯に白文字（ざぶとん） / 白い帯に黒文字 / シンプルな白文字 / 説明の青フチ / タイプライター風
    • 見出し向け: 幅いっぱいの見出し / 大きな白文字 / 金色の見出し / しっとり明朝
    • 強調・ツッコミ: 立体の黄色 / 赤いツッコミ / 色文字＋白黒フチ（話す人の色分け） / 黄色のポップ / ネオン（光る水色）
    • 飾り・札: コメントの札 / パステルの吹き出し風
  • フォント 7 種、サイズ、太さ、フチ（2 重）、影、背景帯、揃え、折り返し幅
  • 出てくるときの動き — ポップ / フェード / 上下左右スライド / ズーム / バウンス / タイプライター / ワイプ / ブレ
  • プレビューの上で直接ドラッグして位置を決められます
  • タイムラインのクリップなので、出したい場面に合わせて始まりと長さを決められます
  • 絵文字タブ — 入れた画像を、文字と同じようにテロップの中に入れられます

字幕（音から自動で文字起こし）

タイムラインの音から文字を起こして、時刻付きのテロップを一気に並べます。音は外へ送らず、ブラウザの中で処理します。

  1. 起こしたいクリップをタイムラインで選びます（Shift・Ctrl で複数、Ctrl/⌘+A で全部）。何も選ばなければ「どの素材から」で選んだ 1 つを使います
  2. インスペクタの字幕の欄で「音から文字を起こす」を押します
  3. 各クリップの位置に合わせて字幕が並びます。長い行は読みやすい所で割り、短すぎる行は少し伸ばします
  • 「くわしい設定」で、見た目・1 枚の文字数・精度（モデル）を変えられます
モデル 日本語
large-v3-turbo いちばん良い。ただし重い（GPU のある端末向け）
small ぎりぎり使える
base 粗い
  • NAS（Docker 版）から開いたときに使えます。 iPad アプリ版と、パソコンでファイルから開いたときは使えません（理由が画面に出ます）
  • 初めて使うときは、文字起こしの部品とモデルをネットから取ってくるので時間がかかります

わたし辞書（字幕の直しを覚える）

文字起こしは、人の名前・ゲームの用語・いつもの言い回しを、毎回同じように間違えます。1 度手で直せば、次からは自動で直ります。

  • 覚える: 字幕（種類＝字幕のテロップ）をインスペクタのテキスト欄か台本で直し、欄から離れると、変えた所を覚えて「「りく」→「陸」をわたし辞書に覚えました」と出ます。違っていたら、その場で 覚えない を押してください
    • 1 文字だけの直し（「会う」→「合う」）は、関係ない所まで変わらないよう、前後の字も含めて覚えます
    • 句読点を足しただけ・行の分け方を変えただけ・行の大半を書き直したときは覚えません。「えーと」のような 2 文字以上の口癖を消したときは、消すことを覚えます
    • 見出しや飾りの文字は覚えません
  • 直す: 次に音から字幕を起こしたとき、置く前に自動で直します（「わたし辞書で ○ か所直しました」と出ます）
  • 見る・足す・消す: テンプレート集のページの「わたし辞書」。手で「間違える言葉 → 正しい言葉」を足すこともできます。「いまのタイムラインの字幕に当てる」で、すでに置いてある字幕もまとめて直せます（「戻す」で戻せます）
  • 辞書は使う人（プロフィール）ごとに、この端末に覚えます

音

  • クリップごとの音量・ミュート、繰り返し（ループ）、フェードイン / アウト、段ごとのミュート
  • 効果音や BGM は入っていません。使う音は、ほかの素材と同じように取り込んでください（以前の版が入れていた効果音 8 種は、タイムラインで使っていなければ自動で片付けます）

台本で直す

左の 「台本」 タブに、プロジェクトの中身が読み物の形で並びます。「どの言葉が、いつ、どの順で出るか」を上から読めます。

  • その場で書き換えられます。 タイムラインにもプレビューにもすぐ反映されます
  • 行を押すと、そのクリップを選んで頭出しします
  • 読むには短すぎる行に ⚠ が出ます
  • いらない行はその場で消せます

自動解析（試験的）

映像クリップを選ぶと、インスペクタの 自動 タブに 「自動で分ける・切り出す（試験的）」 が出ます（かんたん表示でも同じ）。 押したあとは 元に戻す 1 回で戻ります。

  • 場面の変わり目で分割（シーン分割） — 場面の切り替わりを見つけて、場面ごとにクリップを割ります
  • 被写体を追って切り出す — 横長の素材から縦型を切り出すとき、枠を被写体に合わせます。枠が動く所でクリップが割れます
  • 表紙の候補 — 表紙に使えそうなコマを 3 枚選びます。「ここへ移動」と「画像で保存（PNG）」ができます

iPad では処理が遅めです。長い範囲を解析するときは、進み具合を見て待ってください。

テキストスタイル（文字の見た目を作る）

上の 「テキストスタイル」 で、テロップの見た目を見本を見ながら作って、保存できます。

  • フォント — 最初から入っているものに加えて、自分で足せます（「フォントを足す」）
    • ファイルから足す: .ttf .otf .woff .woff2。この端末に取っておくので、ネットが無くても使えます
    • Google Fonts の名前で足す: 例「Dela Gothic One」（fonts.google.com で探せます）。使うたびにネットから読みます
    • 日本語の字が入っていない英字フォントでも、日本語の部分は標準のフォントで出ます。足したフォントは一覧から消せます
  • 太さ（細い / ふつう / 太い / 極太、細かく 100〜900）・大きさ・文字の色
  • 輪郭線 — なし / 1 重 / 2 重。2 重にすると、内側の線のさらに外へもう 1 本引けます（色と太さをそれぞれ決める）
  • 影・字間・行間・帯（文字の後ろの色）・見出し／飾りとして使うか
  • 見本の文字と背景（暗い / 明るい / 映像っぽい）は変えられます。「見本から始める」で、最初から入っているスタイルを土台にできます
  • 保存 すると左に並びます。押せば直せます（上書き・別のスタイルとして保存・消す）
  • 使う: エディタでテロップを選び、テキストの「スタイル」→ 自分のスタイル から押すと、文字はそのままで見た目だけ変わります。エディタでテロップを選んでからこの画面を開けば、「選んでいるテロップに当てる」でもまとめて当てられます
  • エディタの「このスタイルをテンプレートに保存」でも足せます（名前は「スタイル 1」などで入るので、この画面で直してください）

テンプレート

テロップのスタイル・タイムラインの組み方（動画レイアウト）・3 分割の自分の型を保存して、呼び出せます。わたし辞書（字幕の直し）もここで見られます。

書き出す

右上の 「書き出し」 を押し、次を選んで「書き出す」を押します。

  • 画角（9:16 / 1:1 / 4:5 / 16:9）と画質（1080p / 720p / 480p）。かんたん表示では「どこに投稿しますか？」と「きれい / ふつう / 軽い」
  • 形式 — MP4 か WebM。カメラロールへ保存するなら MP4 を選んでください
  • ファイルの大きさ — きれい優先 / おすすめ / 小さく（くわしく表示では 数値で＝ビットレートを決める）。最初は おすすめ です
    • 画質を目安にして書き出すので、動きの少ない所（3 分割の背景や顔の帯、話している場面）は小さく、動きの多い所はちゃんと使います。見た目はほとんど変えずに、以前（8 Mbps 決め打ち）より軽くなります（試した 12 秒の 3 分割で 1080p は約 3 割、720p は約半分）
    • 選んだものは次も使います。iPad など、画質を目安にできない環境では、その段に合ったビットレートで書き出します
  • 音量を整えて書き出す（試験的） — 音量を SNS 向けの大きさ（-14 LUFS）に揃え、割れそうな所だけ抑えます。10 分までの動画で使えます

確かめリスト — 書き出しを開くと、いちばん上に、投稿してから気づくと困る所が時刻つきで並びます。押すと、その場所へ飛んで（関わるクリップも選ばれて）直せます。直さなくても書き出せます。

  • 字幕が速すぎて読み切れない（1 秒に 9 文字より速い・0.6 秒より短い）
  • 字幕が 2 つ同じ所に重なっている・文字が画面からはみ出している
  • 文字が TikTok・Shorts・Reels のボタンや説明文に隠れる所にかかっている（縦長のとき。どのサービスでも隠れないよう広めに見ています）
  • 3 分割で、字幕が下の帯（顔）にかかっている
  • 見出しが「見出しを入れる」のまま・文字の入っていないテロップ
  • 黒い画面が頭や途中に挟まっている
  • 縦長で 3 分を超えている（Shorts・Reels の上限）
  • 字幕が読めるか — 縁が太すぎて文字が潰れる字幕（縁の太さが文字の大きさの 22% を超える）・小さすぎる字幕（スマホで読みにくい大きさ）を知らせます
  • 話者 — 声で決めきれず、色を付けていない字幕を知らせます
  • 音も調べる を押すと、さらに 2 秒以上の無音・頭 3 秒が静か・音割れも調べます（10 分までの作品）

まとめて書き出す — 「書き出す」の下で、作るものを選んで 1 回押すだけで、続けて全部作って保存します。

  • 字幕あり と 字幕なし（字幕があるときだけ）。字幕なしでも、見出しや飾りの文字は残ります

  • 投稿メモ — タイトル（見出しの文字。無ければ作品名）・説明（タイトル＋タグ）・タグ・長さ・字幕の全文。そのまま投稿の画面に貼れます

    • タグは空白で区切って入れます（# は付けなくてよい）。一度入れたタグと、選んだ組み合わせは次も残っています
    • パソコンでは文字のファイル（_post_….txt）も保存します。iPad アプリでは保存先がカメラロールなので、画面の「投稿メモをコピー」を使ってください

  • ファイル名には版の印が入ります（字幕あり _sub_・字幕なし _nosub_）。ひとつずつ「字幕を入れずに書き出す」で書き出したときも _nosub_ が付きます

  • 途中で止まっても、続きから — 1 本保存するたびに記録します。途中でブラウザやアプリが落ちても、もう一度「書き出し」を開くと 「前回のまとめ書き出しが、途中で止まっています」と出るので、続きから書き出す を押すと残りだけ作ります。 作品の中身や設定を変えていたら、別の書き出しとして最初から作ります。1 本の途中からは再開できません（再開は「本」の単位）

完成品 — 書き出した作品は、上のバーの「完成品」のページに 確認待ち で並びます（確認待ちの数が、バーに出ます）。

  • 見て確かめたら 確認した、投稿したら 投稿した を押して進めます（1 つ戻すこともできます）。自動で投稿することはありません
  • メモ欄に、どこへ投稿したか・直したい所などを書いておけます。まとめ書き出しで作ったものは、投稿メモをコピー もここからできます
  • 覚えるのは名前や長さなどの情報だけです。動画のファイルは、保存した先（ダウンロード・カメラロール）にあります。「一覧から外す」でも、ファイルは消えません

話者の要確認 — 字幕を声で 2 人に振り分けたとき、どちらの声か決めきれなかった行は、色を付けずに「要確認」の一覧に並べます。 行を押すとその場面を再生するので、聞いて「話者1」「話者2」を選んでください（点線が付いているほうが「たぶんこちら」）。

書き出し中はタブを開いたままにしてください。かかる時間は素材の重さしだいで、動画の長さより短いことも長いこともあります。

長い・大きい動画のとき

  • 保存領域が足りないと見込まれるときは、書き始める前に知らせます
  • Safari や iPad アプリ版で長い動画を書き出すと、メモリが足りずに落ちることがあります。いくつかに分けて書き出すのが確実です

NAS に置いて何人かで使う

社内の NAS に置けば、URL を 1 つ配るだけで iPad でも PC でも使えます。更新は NAS のファイルを差し替えるだけです。

  • 共有素材をそのまま使う — 素材パネルの「共有」から NAS のフォルダを開いて、コピーせずに追加できます
  • プロジェクトを人に渡す — 「設定 > プロジェクトの受け渡し」からファイル 1 つで書き出せます。同じ共有フォルダが見える人なら、そのまま開けます。自分の端末から入れた素材は運べません（書き出すときに名前を知らせます）
  • 字幕の文字起こしが使えます
  • 長い動画は、NAS が作る軽い複製で、プレビューが軽くなります
  • https で配ってください。 http だと書き出しが遅くなり、コマ落ちすることがあります
  • 同時編集はできません。共有されるのは素材だけで、プロジェクトと設定は各自のブラウザの中です

置き方（nginx と docker compose、UGREEN NAS での手順、外から使うための Cloudflare Tunnel）は deploy/nas/README.md にあります。

動作環境

Chrome / Edge がおすすめです（MP4 で書き出せます）。Safari 17 以降でも動きます。 Firefox でも編集・書き出しはできますが、出力は WebM になります。

困ったとき・できないこと

  • プレビューが重い — 設定の「プレビューの画質」を「軽い」にしてください。それでも重いときは、解像度を落とした素材を使うのが確実です
  • iPad で音が出なくなった（電話・ほかのアプリの音・画面ロックのあと）— 再生をもう一度押すか、画面のどこかを触ると戻ります
  • iPad アプリが落ちる — 設定の「この端末の診断」に、メモリ警告の回数が出ます。知らせてもらうときの手がかりになります
  • 素材・プロジェクト・設定はブラウザの中に保存されます。 ブラウザのデータを消すと失われます
  • 同じ段の上でクリップを重ねることはできません（重なった部分は上書きされます）
  • 言語を英語にしても、一部の表示は日本語のままです
