# タテヨコ Studio

ブラウザだけで完結する、**ショート動画（縦型）専用**のビデオエディタです。
TikTok / Instagram Reels / YouTube Shorts に上げる 15〜60 秒の動画を、素材を放り込んでから書き出すまで 1 画面で作れます。

素材の読み込みも編集も書き出しも、すべてブラウザの中で処理します。**動画がサーバーに送られることは一切ありません。**

```bash
npm install
npm run dev      # http://localhost:5173
```

| コマンド | 内容 |
| --- | --- |
| `npm run dev` | 開発サーバーを起動 |
| `npm run build` | 型チェック＋本番ビルド（`dist/`） |
| `npm run preview` | ビルド結果をローカル配信 |
| `npm run typecheck` | 型チェックのみ |

ビルド結果は静的ファイルなので、`dist/` をそのまま任意のホスティングに置けば動きます。

## できること

**素材**
動画・画像・音声をドラッグ＆ドロップで読み込み。画像は静止画クリップ（既定 3 秒）として並べられます。

**画角**
9:16 / 1:1 / 4:5 / 16:9 をワンタップで切り替え。出力は 1080 幅基準です。
横型の素材を縦型に転用するときのために、クリップごとに収め方を選べます。

- **全画面** … 画面いっぱいに敷いて、はみ出しはカット
- **ぼかし背景** … 全体を映して、余白を同じ映像のぼかしで埋める
- **全体表示** … 全体を映して、余白は背景色

**カット編集**
再生位置で分割（`S`）、両端のハンドルでトリム、ドラッグで並べ替え、複製、削除。
クリップは常に隙間なく詰められるので、消したり足したりしても穴が空きません。

**画づくり**
プレビューを直接ドラッグして位置調整、ホイールでズーム。速度（0.25〜3 倍）、回転、明るさ / コントラスト / 彩度 / ぼかし、フィルタープリセット 8 種、前後のフェード。

**テキスト**
字幕・見出し・白ヌキ帯・ネオン・タイプの 5 スタイルをプリセットで用意。
フォント、サイズ、フチ、影、背景帯、揃え、折り返し幅、傾きを個別に調整でき、
アニメーション（フェード / ポップ / スライド / タイプライター）も選べます。
プレビュー上でそのままドラッグして動かせます。

**音**
クリップごとの音量とミュート、BGM トラック（音量・フェードイン / アウト・ループ）。

**ガイド**
SNS の UI（上部ヘッダ・下部キャプション・右のボタン列）に隠れやすい範囲を破線で表示します。文字がボタンに重ならないか、書き出す前に確認できます。

**書き出し**
MP4（H.264 + AAC、対応ブラウザの場合）または WebM（VP9 + Opus）。画質 3 段階とビットレートを選べます。

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Space` | 再生 / 一時停止 |
| `←` `→` | 1 フレーム移動（`Shift` で 1 秒） |
| `S` | 再生位置で分割 |
| `T` | テキストを追加 |
| `M` | 選択クリップのミュート切替 |
| `Delete` | 選択中のクリップ / テキストを削除 |
| `Ctrl` / `⌘` + `Z` | 元に戻す（`Shift` 併用でやり直す） |
| `Ctrl` / `⌘` + `D` | クリップを複製 |
| `Home` / `End` | 先頭 / 末尾へ |

## 動作環境

Chrome / Edge を推奨します（H.264 の MP4 で書き出せます）。Safari 17 以降でも動きます。
Firefox でも編集・書き出しはできますが、出力は WebM になります。

## 仕組み

外部の動画ライブラリ（ffmpeg.wasm など）を使わず、ブラウザ標準の API だけで組み立てています。

| 役割 | 実装 |
| --- | --- |
| 合成 | `src/engine/renderer.ts` — 1 フレームをキャンバスへ描く。プレビューと書き出しで同じ関数を使うので、見た目がズレません |
| 再生 | `src/engine/player.ts` — 壁時計を基準に時間を進め、各クリップの `<video>` をそこへ追従させます |
| 音 | `src/engine/audio.ts` — WebAudio のミキサ。クリップ音量・BGM・フェードを GainNode で処理し、同じグラフから書き出し用のストリームを取り出します |
| 書き出し | `src/engine/exporter.ts` — キャンバスを実時間で再生しながら `MediaRecorder` で収録します |
| 尺の補正 | `src/engine/webm.ts` — `MediaRecorder` の WebM には尺が書かれないので、EBML を最小限だけ書き換えて埋めます |
| 状態 | `src/store/editor.tsx` — プロジェクトは JSON 化できるデータだけで持ち、履歴（元に戻す / やり直す）を管理します。素材の実体は `src/engine/media.ts` のレジストリ側 |

描画座標は常に「プロジェクト座標（例: 1080×1920）」で計算し、プレビューと書き出しの解像度差はキャンバスのスケールだけで吸収しています。

## 制限

- **書き出しは実時間です。** 実際に再生しながら録画するため、60 秒の動画の書き出しには約 60 秒かかります。途中でタブを裏に回すと描画が止まることがあるので、開いたままお待ちください。
- **プロジェクトは保存されません。** リロードすると素材ごと消えます（動画ファイルをブラウザ内に持ち続けない設計のため）。書き出したファイルを保存してください。
- 映像トラックは 1 本です。ピクチャーインピクチャーや画面分割はできません。
- クリップ間のトランジションは、黒へのフェードイン / フェードアウトのみです。
